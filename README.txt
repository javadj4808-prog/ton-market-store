TON MARKET — نسخه شروع برای راه‌اندازی امن

ویژگی‌ها:
- صفحه فارسی و راست‌چین برای خرید دقیقاً بسته ۵ TON
- دریافت شناسه دستگاه از query string: /?deviceId=DEVICE_ID
- مشتری فقط شماره موبایل را وارد می‌کند
- ساخت سفارش در SQLite روی سرور
- اتصال درخواست پرداخت و تأیید سمت سرور با زرین‌پال
- پنل مدیر در /admin.html با فهرست سفارش‌ها
- پس از ارسال دستی کد، مدیر می‌تواند وضعیت سفارش را به «code_sent» تغییر دهد

مهم:
این پروژه هنوز فروشگاه آماده انتشار عمومی نیست. تا متغیرهای محیطی و درگاه واقعی تنظیم و آزمایش نشوند، پرداخت فعال نمی‌شود. اعتبار پذیرندگی زرین‌پال و مجاز بودن نوع فعالیت را مستقیماً با زرین‌پال بررسی کنید.

راه‌اندازی آزمایشی:
1) Node.js نسخه 20 یا جدیدتر نصب کنید.
2) در این پوشه اجرا کنید: npm install
3) .env.example را به .env کپی کنید.
4) مقادیر ADMIN_PASSWORD و SESSION_SECRET را با رمزها/کلیدهای طولانی و تصادفی جایگزین کنید.
5) TON_PRICE_TOMAN را با قیمت تأییدشده ۱ TON به تومان تنظیم کنید؛ جمع سفارش ۵ برابر آن است. مقدار 0 عمداً پرداخت و قیمت را غیرفعال می‌کند.
6) برای آزمایش از حساب/تنظیمات sandbox زرین‌پال استفاده کنید. Merchant ID معتبر و متناسب با محیط لازم است.
7) اجرا: npm start
8) صفحه اصلی: http://localhost:3000
9) پنل مدیر: http://localhost:3000/admin.html

انتشار:
این پروژه به یک میزبان Node.js نیاز دارد؛ Cloudflare Pages به‌تنهایی برای اجرای server.js و SQLite محلی مناسب نیست. از یک سرویس میزبانی Node.js با دیسک پایدار استفاده کنید یا backend و database را به سرویس‌های مدیریت‌شده منتقل کنید. قبل از انتشار عمومی، HTTPS، پشتیبان‌گیری امن، سیاست حریم خصوصی، محدودیت دسترسی مدیر، و تست پرداخت موفق/ناموفق/تکراری را بررسی کنید.

اتصال برنامه اندروید:
برنامه باید صفحه را با URL-encoded شناسه دستگاه باز کند، نمونه:
https://YOUR-DOMAIN/?deviceId=DEVICE_ID
شناسه دستگاه در URL قابل مشاهده است؛ آن را اطلاعات محرمانه یا اثبات هویت تلقی نکنید. اعتبار سفارش و فعال‌سازی باید در سمت سرور کنترل شود.

قیمت:
در این نسخه قیمت از TON_PRICE_TOMAN سرور خوانده می‌شود و خودکار از بازار دریافت نمی‌شود. قبل از فروش واقعی، منبع نرخ معتبر و قابل اعتماد را به سرور وصل کنید یا نرخ را به‌صورت کنترل‌شده به‌روز کنید. نرخ ثابت/دستکاری‌شده را به‌عنوان نرخ لحظه‌ای معرفی نکنید.
